# ChatBot GUI POE Part 2

## Description
This is a C# Windows Forms chatbot application developed for cybersecurity awareness and education.

The chatbot helps users learn about:
- Password safety
- Phishing
- Online scams
- Malware
- Privacy
- Firewalls
- Online safety

## Features
- Graphical User Interface (GUI)
- Voice greeting using WAV audio
- Sentiment detection
- Random chatbot responses
- User name recognition
- Favourite topic memory
- Cybersecurity education tips

## Technologies Used
- C#
- Windows Forms
- NAudio Library

## How to Run the Project
1. Open the solution file in Visual Studio.
2. Build the project.
3. Run the application.
